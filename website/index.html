Politique de Confidentialité

Dernière mise à jour : 24/02/2026

1. Collecte des données

Explore Browser est conçu pour respecter votre vie privée. Nous ne collectons aucune donnée de navigation, historique ou mot de passe sur nos serveurs. Toutes vos données restent stockées localement sur votre machine.

2. Services Tiers

Le navigateur utilise les services de Google et Bing uniquement pour effectuer vos recherches. Ces services sont soumis à leurs propres politiques de confidentialité.

3. Mises à jour

Le navigateur vérifie automatiquement les mises à jour via GitHub. Aucune donnée personnelle n'est transmise lors de ce processus.
